What you need in order to run Blitz intro :
* a 68K Mac with a 256 or 32768 color video card
* even better, a PowerMac

Configuration :
very funny in fact : open the file Blitz.cfg and hit :
16 to display in 32768 colors
8 to display in 256 colors

The intro has been tested successfully on :
II Fx
LC 630
PowerMac 7100,8100,8500

Yo ! Here is finally the patched version of Blitz intro, originally coded in 2 days. The low level display routines now work on recent PowerMac ( 7500, 7200, 7600)...This version isn't fully optimized so if you own a 68K mac, the display will certainly be flicky.

	This intro features a few functions of the Graphic Motion System library. If you want more informations about it, contact me.

	I hope that demomakers will soon notice that PowerPC platforms are THE BEST and most powerful for demos. If you're interested in joining me and form a reel mac demo group, contact me.
