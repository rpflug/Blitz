Blitz intro is "little FAT" intro coded in two days, so I haven't made a lot of tests that's why I can't be sure that it isn't bugged. Contact me if so.
	It features a few functions of the Graphic Motion System library. If you want more informations about it, contact me.

	Hope that demomakers will soon notice that PowerMac is THE BEST and most powerful platform for creating demos. If you're interested in joining Synergy and become the first mac demomaker group, contact me.
